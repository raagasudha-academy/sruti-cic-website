# Śruti CIC Website — local prototype

A fresh React/Vite website prototype for Śruti CIC, built only from information supplied in the project materials and conversation. It deliberately avoids inventing programmes, claims, testimonials, contact details, fees or schedules.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite (normally `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Content included

- Śruti CIC purpose and core values
- Current adult/family sessions
- Five registered online children's Vedam groups
- Dharma Sundays and supplied participation count
- Performing arts and selfless service
- 18 April 2026 tree-planting activity and supplied figures
- Safeguarding statement and directors
- The Great Hanuman Chalisa event, registration and FAQ links

## Important content rule

Before publishing, verify every date, time, venue, participant number and external link with the Śruti CIC team. Do not add testimonials, impact claims, teacher biographies, fees, contact details or accreditation unless they are supplied and approved.

## Suggested next steps

1. Replace the temporary “Ś” brand mark with the approved Śruti logo if available.
2. Add approved photographs from real classes and service activities.
3. Add approved social-media links and contact details.
4. Add real safeguarding/governance document links when supplied.
5. Connect the purchased domain after team review.
6. For maintainability, move event/class data to a small CMS only when the team needs non-developer editing.

## Stack

- React
- TypeScript
- Vite
- lucide-react
- Plain responsive CSS

There is intentionally no backend in this prototype because the current requirements are public information, external registration forms and static content. A backend would add complexity without a confirmed data requirement.
